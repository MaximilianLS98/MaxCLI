MaxCLI 2.0 requires Python 3.10+ on macOS or Linux. Stable installations now run published GitHub releases in managed virtual environments. For a legacy installation, rerun the current `bootstrap.sh`, put `~/.local/bin` first on PATH, and run `hash -r`; use `--replace-existing` if the installer reports an executable conflict. Existing managed installations can run `max update`. Use `bootstrap.sh --dev "$PWD" --with-dev-tools` to install your editable checkout as `max-dev`, with separate development configuration. See [installation and migration](https://github.com/MaximilianLS98/MaxCLI/blob/v2.0.0/docs/INSTALLATION.md).
