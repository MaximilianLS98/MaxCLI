Save named command templates with `max gm commands` in MaxCLI settings, prompt for variables with defaults and choices, and import or export shareable JSON command packs. The built-in `max gm appstore` shortcut resizes screenshots to 1284x2778 pixels and flattens transparency onto white using ImageMagick or GraphicsMagick.

Image recipes preserve input files and require explicit overwrite of existing outputs. Saved commands are included in encrypted configuration backups, omitted from unencrypted backups, and checked by `max doctor`.
